# Changelog

All notable changes to CodeFox are documented here.

## [0.0.3] - 2026-11-05

- Automatically open the Fox view when VS Code starts.
- Added the `codefox.showOnStartup` setting to disable automatic opening.

## [0.0.2] - 2026-11-05

- Moved the Fox view into the Explorer sidebar so it can stay visible alongside the editor.

## [0.0.1] - 2026-11-05

- Initial release of the animated fox view for the VS Code bottom panel.
- Added jump, sprint, crouch, wandering, and sleep behaviors.
- Added settings for sprite scale and autonomous behavior.
